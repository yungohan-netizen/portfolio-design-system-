# Halo Site — Marketing UI Kit

A single-page marketing site for Halo Studio. Demonstrates the **studio-facing** half of the design system: hero with halation, eyebrows, bento feature grid, process steps, pricing tiers, testimonial row, FAQ, and footer.

## Files
- `index.html` — entry point, composes all components, loads `colors_and_type.css`.
- `Nav.jsx` — sticky top nav with frosted backdrop.
- `Hero.jsx` — full-bleed hero with accent halation + tilted product screenshot.
- `Logos.jsx` — "trusted by" wordmark strip.
- `Features.jsx` — 4-up bento with glow-corner cards.
- `Process.jsx` — 3-step process with numbered cards.
- `Pricing.jsx` — 3-tier pricing with featured middle plan.
- `Testimonials.jsx` — quote carousel-row.
- `FAQ.jsx` — accordion.
- `Footer.jsx` — final CTA + footer cluster.

## What's interactive
- Sticky nav reacts to scroll (backdrop opacity ramps).
- Pricing toggles monthly/annual.
- FAQ rows open/close.
- All buttons + chips have proper hover/press states.

Open `index.html` to see it.
